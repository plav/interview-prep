#DOC Languages
#SHEET Java
I What are the JVM, JRE and JDK, and how does Java code run? || The JDK is the development kit, including the compiler. The JRE is the runtime libraries plus the JVM. `javac` compiles source to bytecode; the JVM loads it, interprets it at first, then JIT-compiles hot code to machine code, and manages memory with a garbage collector.
I Explain the `equals` and `hashCode` contract. || Equal objects must return equal hash codes. If you override `equals` and not `hashCode`, hash-based collections look in the wrong bucket and "lose" objects. Records generate both correctly.
I How does `HashMap` work? || An array of buckets indexed by the key's hash. Collisions go into a list, and since Java 8 a crowded bucket becomes a balanced tree. It resizes when the load factor (default 0.75) is exceeded. Average lookup is O(1).
I Virtual threads or platform threads? || Virtual threads suit high-concurrency blocking I/O: write simple synchronous code and run one virtual thread per task. Platform thread pools suit CPU-bound work sized to the core count. Don't pool virtual threads, and avoid heavy `ThreadLocal` use with them.
I Checked or unchecked exceptions? || Checked exceptions force callers to handle recoverable conditions at compile time. Unchecked ones signal programming errors or failures you can't recover from locally. Many modern APIs favour unchecked exceptions, translating at boundaries.
I How does garbage collection work in Java? || It's generational: most objects die young and are collected cheaply, and long-lived objects are promoted and collected less often. G1 balances throughput and pause time; ZGC targets very short pauses on large heaps. Tune by measuring with JFR or GC logs.
I Why doesn't `@Transactional` work when one method calls another in the same class? || Spring applies it through a proxy, and an internal call never passes through that proxy. Move the method to another bean, or restructure the code.
#SHEET C#
I Value types or reference types, and when would you use a struct? || Value types (structs) are copied on assignment and usually live inline; reference types (classes) are shared through references on the heap. Use small, immutable structs for values such as money or coordinates, and classes for everything else. Records give value equality to either.
I How does async/await work under the hood in C#? || The compiler rewrites an async method into a state machine. At each `await` on an incomplete task, the method returns to its caller and registers a continuation, so no thread waits. When the I/O completes, the continuation runs on a thread-pool thread, or the captured synchronisation context if there is one.
I What are the dependency injection lifetimes, and what's a captive dependency? || Transient creates a new instance each time, scoped gives one per request, and singleton one for the app's life. A captive dependency is a shorter-lived service trapped inside a longer-lived one, for example a scoped `DbContext` inside a singleton, which causes shared state and threading bugs.
I What's the difference between `IEnumerable` and `IQueryable`? || `IEnumerable` runs LINQ in memory. `IQueryable` builds an expression tree that a provider such as EF Core translates to SQL. Filtering after switching to `IEnumerable` loads everything first.
I `throw;` or `throw ex;`? || `throw;` rethrows and keeps the original stack trace; `throw ex;` resets it, which loses where the error actually happened.
I How does .NET garbage collection work, and where does `IDisposable` fit? || The GC is generational (generations 0, 1 and 2, plus a large-object heap) and reclaims managed memory automatically. `IDisposable` and `using` release unmanaged resources, such as sockets, file handles and connections, at a known point rather than whenever the GC runs.
#SHEET JavaScript
I Explain the event loop. || One thread runs your code. When the call stack is empty, the loop drains the microtask queue (promise callbacks), then takes the next task (a timer, I/O or event); in browsers it may render in between. That's why a resolved promise's `then` runs before a `setTimeout(0)`.
I What is a closure? Give a practical use. || A function that keeps access to variables from the scope it was created in, even after that scope has returned. It's used for private state, factories, memoisation and event handlers. The classic bug is `var` in loops, which shares one binding across iterations.
I How does `this` work? || It's determined by the call site: a method call gives the object, a plain call gives `undefined` in strict mode, `new` gives the new instance, and `call`/`apply`/`bind` set it explicitly. Arrow functions take `this` from the surrounding scope.
I `==` or `===`? `null` or `undefined`? || `===` doesn't convert types. `undefined` means not assigned; `null` means intentionally empty. `x == null` is the one accepted use of `==`, because it checks for both.
I `Promise.all`, `allSettled`, `race` or `any`? || `all` waits for every promise and rejects on the first failure. `allSettled` waits for every promise and reports each outcome. `race` settles with the first to settle, success or failure. `any` resolves with the first success and rejects only if all fail.
I How do you keep the UI responsive during heavy work? || Break it into chunks and yield to the event loop, move it to a Web Worker, or do less work: virtualise long lists and debounce input. Measure with the Performance panel and INP.
#SHEET HTML and CSS
I Flexbox or grid? || Use flexbox for one dimension, where content drives the size: toolbars, rows of buttons, centring. Use grid for two dimensions, where layout drives the content: page structure and card grids. They're often combined.
I How does the cascade decide which rule wins? || In order: origin and importance, then cascade layers (a later layer wins), then specificity (IDs, then classes, attributes and pseudo-classes, then elements), then source order. Layers and `:where()` keep specificity manageable.
I Container queries or media queries? || Media queries respond to the viewport and user preferences; container queries respond to the space a component actually has. That makes components reusable in sidebars, modals and grids without page-specific overrides.
I How do you build an accessible modal? || Use `<dialog>` with `showModal()`. That gives a focusable modal, an inert background, Escape to close and the top layer. Give it an accessible name with `aria-labelledby`, put focus on a sensible element, and return focus to the trigger when it closes.
I What are the Core Web Vitals, and how would you improve LCP? || LCP, INP and CLS. For LCP: find the LCP element, make it discoverable early in the HTML, give it `fetchpriority="high"`, don't lazy-load it, compress it, cut render-blocking resources, and improve server response time.
#SHEET Python
I What is the GIL, and how do you do CPU-bound work in Python? || In the standard CPython build, the global interpreter lock lets one thread execute Python bytecode at a time. That simplifies memory management but prevents parallel CPU work in threads. For CPU-bound work, use processes (`ProcessPoolExecutor`), native libraries that release the GIL (NumPy, Polars), sub-interpreters, or the free-threaded build, which has been officially supported since 3.14.
I asyncio, threads or processes: how do you choose? || Use asyncio for many concurrent I/O operations with async libraries, threads for I/O with blocking libraries, and processes or free-threading for CPU-bound work. Never block inside async code.
I List, tuple, set or dict? || A list is ordered and mutable, with O(n) membership checks. A tuple is immutable and hashable if its contents are. Sets and dicts are hash tables with O(1) average lookup, and dicts keep insertion order. Pick based on the access pattern.
I What are generators, and why use them? || Functions with `yield` that produce values lazily, one at a time. They give constant memory for large or infinite streams, can be composed into pipelines, and do no work until consumed.
I How does Python manage memory? || Primarily reference counting, which frees an object when its last reference goes, plus a cyclic garbage collector for reference cycles. Leaks usually come from long-lived references, such as global caches, closures and listeners.
I Why is `def f(items=[])` a bug? || Defaults are evaluated once, at definition time, so every call shares the same list. Use `None` and create the list inside the function.
#SHEET TypeScript
I `interface` or `type`? || Both describe object shapes. Interfaces support declaration merging and `extends`, and give clearer error messages for object types. Type aliases are needed for unions, tuples, mapped and conditional types. What matters most is a consistent team convention.
I `unknown` or `any`? || `any` disables type checking for that value and everything it touches. `unknown` accepts any value but forces you to narrow it before use, so use it for external data and caught errors.
I What is structural typing, and how do you work around its downsides? || Compatibility is based on shape, not declared names. It's flexible, but it lets values with the same shape but different meaning mix, such as two string IDs. Branded or nominal-style types fix that where it matters.
I What's a discriminated union, and why use one? || A union whose members share a literal tag field. Checking the tag narrows to one member, and a `never` default makes the compiler flag unhandled cases. It's ideal for states, events and API results.
I Does TypeScript make your app type-safe at runtime? || No. Types are erased. Data from the network, storage or users must be validated at the boundary with a schema library, and the types inferred from that schema.
I What changed with TypeScript 7? || The compiler was rewritten in Go, giving roughly ten times faster builds. 6.0 was the bridge release that deprecated legacy options, and 7.0 turns those into errors. The programmatic API isn't stable yet, so tooling such as typescript-eslint and Angular's compiler stays on 6.x for now.
